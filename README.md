# 0 dan dasturgacha — Ta’lim kelishuvi

«0 dan dasturgacha» dasturlash va IT kursi uchun o‘quvchi, ota-ona va o‘qituvchi o‘rtasidagi rasmiy ta’lim olish va ichki tartib kelishuvi veb-hujjati.

## Kurs va o‘qituvchi ma’lumotlari

- **O‘qituvchi:** Samar Baxtiyarov
- **Kurs nomi:** «0 dan dasturgacha»
- **Yo‘nalish:** Dasturlash va IT
- **Dars kunlari:** Dushanba / Chorshanba / Juma
- **Oylik to‘lov:** 150 000 so‘m / oy

---

## Asosiy xususiyatlar

1. **Zamonaviy rasmiy raqamli hujjat:**
   - Hech qanday ortiqcha marketing elementlari, ro‘yxatdan o‘tish shakllari yoki administrator boshqaruv panellarisiz.
   - Barcha 21 ta bo‘lim to‘liq, so‘zma-so‘z o‘zbek lotin imlosida taqdim etilgan.
   - Moddalar aniq raqamlangan (`1.1` – `20.5`) va qulay qator oraliqlari bilan formatlangan.
2. **21-bo‘lim: Tomonlarning ma’lumotlari:**
   - O‘qituvchi: Samar Baxtiyarov
   - O‘quvchi: F.I.Sh., Tug‘ilgan sana, Telefon, Imzo
   - Voyaga yetmagan o‘quvchi uchun ota-ona / qonuniy vakil: F.I.Sh., Telefon, Imzo
   - Sana: «____» ______________ 2026-yil
3. **A4 PDF va Chop etish rejimi:**
   - «PDF / Chop etish» tugmasi orqali to‘g‘ridan-to‘g‘ri brauzerning chop etish oynasi ochiladi.
   - Maxsus `@media print` qoidalari veb-navigatsiya va tugmalarni yashirib, faqat toza rasmiy hujjatni A4 formatida bosmaga chiqaradi.

## Loyihani ishga tushirish

### 1. Bog‘liqliklarni o‘rnatish
```bash
npm install
```

### 2. Dasturni ishga tushirish (Development)
```bash
npm run dev
```
Brauzerda [http://localhost:3000](http://localhost:3000) manzilini oching.

### 3. Production rejimida yig‘ish va ishga tushirish
```bash
npm run build
npm run start
```
